# 教程 17：RFV 用户分层

## 为什么不是标准 RFM

数据没有金额、价格和订单金额，因此不能计算 Monetary。这里使用 RFV：

- R：距观察截止日 `2017-12-04` 的最近活跃天数；
- F：有效行为事件总数；
- V：行为价值分，`pv=1、fav=2、cart=3、buy=5`。

V 的权重是透明的分析假设，不是真实金额。表中同时保留四类行为次数，便于调整权重后复算。

## 评分

R 按业务天数阈值评分。F/V 使用当前用户级样本的分布阈值：F 为 32/74/155，V 为 42/93/188。阈值必须在报告中说明，不可伪装成行业标准。

## 分群

- CORE_VALUE：近期、频次和价值均较高且有购买；
- ACTIVE_BUYER：近期有购买但未达到核心阈值；
- HIGH_INTENT_NON_BUYER：有收藏/加购但没有购买；
- AT_RISK：距截止日四天以上未活跃；
- GENERAL_ACTIVE：其余活跃用户。

分群 CASE 有顺序，用户只进入一个互斥分群。
