# Hive 时区修复验收结果

验收日期：2026-08-13

根因：Hive/JVM 默认 UTC，直接使用 `from_unixtime` 将上海凌晨事件分到前一天。

修复：使用 `from_utc_timestamp(event_ts * 1000, 'Asia/Shanghai')` 显式转换，并重建 DWD、DWS、ADS 日期分区。

|---|---|---|---:|

| DWS 10K | 2017-11-25 | 2017-12-03 | 9,997 |
| ADS 10K | 2017-11-25 | 2017-12-03 | 9,997 |
| DWD 1M | 2017-11-25 | 2017-12-03 | 999,429 |
| DWS 1M | 2017-11-25 | 2017-12-03 | 999,429 |
| ADS 1M | 2017-11-25 | 2017-12-03 | 999,429 |
| DWD 用户级样本 | 2017-11-25 | 2017-12-03 | 976,097 |
