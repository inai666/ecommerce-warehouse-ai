# 教程 18：热门商品与类目分析

## 目标

建立商品和类目表现表，不只看 PV，还同时观察用户覆盖、意向行为、购买事件和购买用户。

## 指标

- event_count：全部行为；
- active_users：互动去重用户；
- pv_count：浏览；
- intent_count：收藏 + 加购；
- buy_count：购买事件；
- buyer_users：购买用户；
- buy_event_rate_pct：购买事件 / 全部事件，仅为事件占比，不是严格漏斗转化率。

## 商品标签

- HIGH_TRAFFIC_NO_BUY：PV 至少 20 且无购买；
- TOP_SELLER：购买事件至少 5；
- NORMAL：其余商品。

阈值是当前样本的分析规则，不是行业标准。高流量无购买只是排查候选，可能受抽样、商品生命周期、价格缺失等因素影响，不能直接断言商品有问题。

## 验收

- 商品行数应等于 DWD 有效商品数 396,750；
- 类目行数应等于 5,788；
- 两张表的事件合计均为 976,097；
- pv 874,147；intent 82,692；buy 19,258；
- `invalid_metric_rows=0`。

## 实际运行记录

- 构建耗时：`72.225 seconds`；
- 构建包含商品和类目两个粒度的去重用户聚合。
