# 教程 14：用户级样本 DWD 清洗

## 目标

把用户级 ODS 清洗为严格漏斗可使用的有效明细，并对所有异常记录保留原因。

- 明细表：`ecommerce_dwd.user_behavior_sequence_detail`
- 异常表：`ecommerce_dwd.user_behavior_sequence_quarantine`
- 存储：ORC
- 明细按 `dt` 分为 9 个日期分区

## 精确对账

```text
976621 ODS = 976097 DWD + 524 quarantine
```

对账差额必须为 0。异常原因：

- `EVENT_TIME_BEFORE_RANGE`：506；
- `EVENT_TIME_AFTER_RANGE`：18。

## 有效层基线

| 检查项 | 预期结果 |
|---|---:|
| 有效用户 | 9,659 |
| 有效商品 | 396,750 |
| 有效类目 | 5,788 |
| pv | 874,147 |
| cart | 54,728 |
| fav | 27,964 |
| buy | 19,258 |

ODS 有 9,660 个用户，而 DWD 有效用户为 9,659。原因是其中 1 个入样用户的所有事件都在业务时间范围外，并非清洗过程无故丢失用户。

## 实际构建耗时

本次三节点虚拟机环境的 DWD 构建耗时为 `28.869 seconds`。该结果包含 Hive 编译、YARN 作业启动、数据清洗、动态分区和 ORC 写入的端到端时间。
