# 电商用户行为分析看板

入口：`dashboard/index.html`

看板使用内嵌 ADS 汇总数据，无需连接 Hadoop、Hive 或互联网。可直接双击打开，也可以在项目根目录启动静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/dashboard/`。

## 页面

- 经营概览：每日趋势、核心指标、严格漏斗、日指标明细；
- 留存与用户：cohort 留存矩阵、RFV 用户分群；
- 商品与类目：热销商品、高流量无购买候选、热门类目。

## 数据口径

- 每日趋势来自固定随机 1M 事件样本；
- 严格漏斗、留存、RFV、商品与类目来自约 1% 用户级固定哈希样本；
- 日期均显式使用 `Asia/Shanghai`；
- V 是行为价值分，不是消费金额；
- 高流量无购买是排查候选，不代表商品存在确定问题。
